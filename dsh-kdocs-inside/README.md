# DSH KDocs Sidebar

金山文档右栏插件，包名 `dsh-kdocs-inside`，当前候选版 **0.4.6-rc.3**。RC / 试用，非稳定版。

## 功能

- 浏览、搜索、阅读和引用云文档；原生紧凑引用保留文件/文件夹资源信息。
- 文件树四种同级排序并保存选择；共享视图按接口支持修改时间排序；不支持项置灰。
- `.otl` 使用紫色文档图标；界面间距、标题和树行高经过调整。
- Desktop PDF 原始下载，Word/PPT 转 PDF，交给 DSH 官方文件查看器。
- PNG/JPEG/GIF/WebP/BMP/ICO/SVG 下载到私有缓存后交给 DSH 内置图片查看器；HEIC/TIFF 暂不支持。
- Agent 提供四个只读工具；签名下载地址与认证信息不传给前端。

## 安装与使用

目标功能基线：macOS DSH Desktop **0.2.1-rc.2**，Node >=22.19。使用官方 kdocs-cli 并在本机完成登录；不随安装包分发认证信息。通过 DSH 插件管理器安装维护者提供的最终 `.tgz`，然后完全退出并重新打开 DSH。已有版本升级保留原配置，更新 Host/schema 后仅刷新页面不足以生效。

点击文档或图片打开原生预览；菜单可刷新本地预览，文本阅读与引用入口保留。Web 沿用既有 iframe 行为，本版不增加 Web 专项适配。

缓存：单文件30MiB，总量120MiB，最多20项；私有临时目录，Unix目录0700/文件0600；下载限时60秒，检查受信HTTPS存储域、文件头、大小与支持的哈希，停止时清理本实例。预览文件不上传第三方服务。

## 源码验证

使用 `pnpm@11.28.5`，执行 `pnpm install --frozen-lockfile`，再执行 `pnpm test`。client.js为手写客户端，无构建步骤。Host核心包仅作为可选peer，由DSH提供，不应作为普通运行依赖重复安装。仓库保留公开合成数据测试，内部账号/材料测试与开发记录不包含在公开快照中。
