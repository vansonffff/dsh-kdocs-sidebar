# 更新日志

## 0.4.6-rc.4 — 2026-11-13（发行候选）

- 新增root Factory `kdocs.workspace`，供其他插件在主工作区嵌入浏览与预览，复用原界面，不新增后台服务或AI工具。
- 浏览/预览使用可注入导航，引用核对当前会话；主工作区与右栏位置记忆分开。旧宿主缺Factory API时保留原右栏。
- Desktop在线打开接入官方Browser Tab，保留旧宿主与修饰键的链接回退；不读取或复制Cookie。
- 修正客户端装载重试的测试夹具；公开快照保留合成测试，不包含实际文档标识、内部文档或开发历史。
- 仅RC，最终tgz的完整Desktop安装/升级、配置冷启动与分发组合仍待验收。

## 0.4.6-rc.3 — 2026-10-23（发行候选）

- 引用文件/文件夹改为紧凑的原生引用组件，保留完整资源语义与文本回退。
- 放宽浏览区域间距与文件树行高，页面标题明确化；加入持久化排序菜单，目录四种排序，共享视图按接口支持修改时间排序。
- `.otl` 智能文档使用紫色文档图标；图片复用私有缓存并交给 DSH 内置图片查看器，保留 PDF/Office 原有预览流程。
- PNG/JPEG/GIF/WebP/BMP/ICO/SVG 支持本地预览；HEIC/TIFF 显示格式提示。缓存大小、权限、下载来源及哈希校验延用现有限制。
- 可选核心 peer 显式纳入已检查的 Desktop 0.2.1-rc.2；不引入第二套运行时核心包。
- 相关本地回归132项通过，另补宿主依赖边界与清单检查；用户确认当前功能可用。完整安装组合、Air 与既有live上游失败分类用例仍需后续验收，不作为稳定版发布。
